# Blox Fruits Rolling System

A small, fan-made Java console game inspired by **Blox Fruits**. Roll for a fruit, manage your in-game money, and decide whether to sell or store what you get.

## Features

- Roll for one of several fruits, each with its own odds
- Start with $100; each roll costs $10
- Sell a fruit for its in-game value or store it in your inventory
- View your inventory and unstore fruits later

## Requirements

- Java 17 or newer

## Run the game

The source file is currently named `BloxFruitsRollingSystem` without a `.java` extension. Rename it to `BloxFruitsRollingSystem.java`, then compile and run it:

```sh
javac BloxFruitsRollingSystem.java
java BloxFruitsRollingSystem
```

Follow the prompts in the console. Enter `roll`, `inv`, `unstore`, or `leave` to choose an action.

## Note

This is a fan-made learning project and is not an official Blox Fruits product.
